# Corn - A RISC-V kernel, from scratch, written without tutorials

This is my RISC-V kernel, that I am writing using a "spec-first" approach. I am not following any tutorials or step-by-step guide, but rather writing everything from first principles. I am following specs, data sheets, documentation and using Claude as a research partner and guide, but *not for generating code*.

> All of the code in this repo is handwritten. Seesion notes are AI generated.
